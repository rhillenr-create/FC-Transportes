# **App Name**: FC Frota

## Core Features:

- Intelligent Maintenance Tool: Uses generative AI as a tool to analyze checklist logs and provide predictive maintenance diagnostics for the fleet based on detected anomalies.
- Logistics Dashboard: Visual summary of total trips, monthly expenses, profit estimation, and critical alerts through modern data visualization charts.
- Fleet Inventory Control: Centralized database of trucks including plates, model, year, and status using Firestore for real-time synchronization.
- Dynamic Checklist System: Interactive pre-trip inspection interface allowing drivers to mark status, add observations, and upload evidence photos to cloud storage.
- Trip & Freight Engine: Automation for calculating trip profitability, fuel consumption, and operational costs per freight in real-time via Firestore data triggers.
- Financial Stream Management: Consolidated record of all entries (freights) and exits (fuel, tolls, maintenance, taxes) for a precise monthly cash flow overview.
- Biometric Authentication: Secure access implementation using Firebase Authentication for drivers and administrators.

## Style Guidelines:

- Primary color: Vibrant Emerald Green (#00FF88) to represent modern logistics and technology.
- Background: Graphite Carbon (#0F1210), a dark, low-saturation hue for a premium, professional SaaS aesthetic.
- Accent color: Neon Lime (#CCFF00), used for secondary CTAs and luminous highlighting of status indicators.
- Font pairing: 'Space Grotesk' for tech-oriented headlines and 'Inter' for data-heavy body text and dashboard statistics (Sans-serif).
- Custom monochrome line icons with occasional neon green fills, reflecting industrial machinery and vehicle parts.
- Professional logistics command center with a fixed dark sidebar, modern top navigation bar, and responsive soft-bordered cards for dashboard widgets.
- Subtle, fluid micro-interactions and transitions to provide a 'premium application' feel during screen switches.
